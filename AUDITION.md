# Music audition list — dance/EDM candidates (CC-BY / CC0)

The problem: the current catalog skews chill/cinematic, but most venues are tagged
house/techno/trance/dnb/synthwave. The fix lives in archive.org's **netlabels**
collection — catalog-numbered, self-published CC releases (the legit vein of free
dance music). Below are the most-downloaded candidates per genre.

**How to use this:** open the links, listen, and mark keepers (`✓`) / rejects (`✗`).
Claude then verifies each keeper's exact license + playable files via the metadata
API and wires them into the catalog/packs with correct genre tags.

## Vetting rules (why some popular hits are ALREADY rejected)

- ✗ **"Vinyl rips" of known artists marked CC0 are piracy** — The Midnight,
  Perturbator, Carpenter Brut, Mitch Murder, Power Glove all showed up tagged
  "public domain." They are not. Never trust a famous name's CC tag.
- ✗ Remixes of commercial songs (a Drake house remix surfaced) — the underlying
  composition isn't CC.
- ✗ Live Music Archive taper recordings (EOTO etc.) — taping policy ≠ redistribution license.
- ✓ Netlabel catalog releases (`[GT###]`, `[onmp###]`, `[USR-###]`…) — legit.

## Synthwave — honest gap

The popular "CC0 synthwave" on archive.org is pirated vinyl rips. Legit options:
keep **SwapXFO** (already in, genuinely CC), lean on **Nightwave Plaza** radio,
and audition `subject:synthwave` netlabel items case-by-case later.

## The structural answer for club genres

Bundled CC can *supplement*, but professionally-curated **radio** is the credible
EDM source: SomaFM Beat Blender (house), DEF CON (techno), Nightwave Plaza
(synthwave) — already one-tap suggestions, reactive on desktop via the proxy.
